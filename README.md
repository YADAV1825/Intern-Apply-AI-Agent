# 🚀 Intern-Apply AI Agent

> **Tactile Neomorphic Outreach Diary & AI Application Engine** built to automate, organize, and accelerate outreach to **1,842+ HR and Talent Acquisition Leaders** across top tech companies and startups.

---

## ✨ Features

- **Soft-UI / Neomorphism Design System:** Clean, tactile, modern neumorphic interface with light and dark mode toggles.
- **1-Click Gmail Web Composer:** Instantly generates pre-filled drafts in Gmail Web (`mailto` link / Gmail Web URI) tailored with personalized cover letters.
- **Company Financial Intelligence:** Live tracking of company valuation, ARR, or funding rounds (e.g. `$93.9M (ARR)`, `$481M (valuation)`, `$451M (funding)`).
- **Smart Sorting & Filtering:**
  - Sort by **Company Name** (A $\rightarrow$ Z, Z $\rightarrow$ A)
  - Sort by **Net Worth / Financials** (High $\rightarrow$ Low numeric weighting)
  - Sort by **Contact Name**, **Original ID (#1 – #1842)**, and **Sent Status**
  - Instant Alphabet quick-jump bar (`ALL`, `A`...`Z`, `#`)
- **Gender-Aware Honorific Engine:** Automatically predicts salutations (`Sir` / `Ma'am`) with an in-UI 1-click switcher to override and save.
- **Disk & Local Persistence:** Real-time persistence to `sent_status.json` via local Vite middleware, `localStorage` backup, plus JSON Export/Import tools.
- **Interactive Letter Preview:** Full modal inspection of the personalized application before dispatching.

---

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite
- **Styling:** Custom Neomorphic Vanilla CSS (CSS Variables, Soft Embossed Shadows, Micro-interactions)
- **Icons:** Lucide React
- **Data & Automation:** Python scripts for dataset normalization, financial metrics enrichment, and bi-directional sync across CSV/XLSX/JSON.

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/YADAV1825/Intern-Apply-AI-Agent.git
cd Intern-Apply-AI-Agent
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### 3. Build for Production
```bash
npm run build
```
